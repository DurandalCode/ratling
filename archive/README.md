# Архив

Генераторы, которые заменили или бросили. Файлы не удалены: на них ссылаются докстринги,
коммиты и живые комментарии. Новую деталь отсюда не начинать — карта живых файлов
в [`docs/status.md`](../docs/status.md).

Лежат плоско, на один уровень ниже корня. Так запасной расчёт `REPO` через два `dirname(__file__)`
по-прежнему находит корень репозитория. `exec` внутри архива указывает сюда же. Живой код архив
не исполняет, кроме одной стороны: `mech_anim.py` сам открывает `pistol/mech_layout.py`
(библиотека куркового пистолета, на месте).

| Файл | Что это |
|---|---|
| `stage3v2_inline.py` | Модуль v2: поршень внутри трубы. Поршень тёк по седлу, ветку бросили. |
| `stage3v2_oring_gauge.py` | Калибр канавок поршня v2. Берёт размеры из `stage3v2_inline.py`. |
| `stage3v3_coaxial.py` | Модуль v3: соосный клапан, камера сзади. Заменён v4 (камера вокруг ствола). |
| `stage4v2_schrader.py` | Казённик на 25 модулей v2, золотники Schrader. Построен на брошенном v2. |
| `pistol_concepts.py`, `pistol_look.py`, `pistol_look_skaven.py` | Ранние эскизы пистолета массами и обликом. |
| `pistol_assembly.py`, `mech_anim.py`, `assembly_anim.py` | Рычажный пистолет и его анимация. Заменены курковым: нужна одна рука. |

Замороженное (селектор, пробка трубки, анимации курка, `pack_mockup.py`) в архив не переезжало:
идея не закрыта либо файл ещё могут перегенерировать.
