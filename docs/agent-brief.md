# Бриф исполнителя тикета

Ты делаешь **один тикет** из `tasks/`. Тикет — закон: в нём сказано, какие файлы трогать, что
изменить и как проверить. Остальной репо (AGENTS.md, docs/status.md) тебе читать **не нужно**;
если тикета не хватает, чтобы сделать работу, — остановись и напиши вопрос (шаг 6).

Проект: печатный проп-реквизит. Почти весь код — скрипты FreeCAD 1.0 (`import FreeCAD`, `Part`),
обычным `python3` они не запускаются.

## Порядок

1. Прочитай тикет целиком. Открой **только** файлы из `allowed` и `read` (если есть).
2. Найди место правки по подсказке тикета (имя константы, функции, строка поиска). Параметры —
   константы в начале генератора.
3. Сделай минимальную правку. Не переименовывай, не переформатируй, не «улучшай» соседний код.
4. Запусти судью:
   ```sh
   python3 tools/verify.py tasks/<тикет>.md
   ```
   Первая проверка идёт ~20–60 с. Последняя строка — `VERDICT: PASS` или `VERDICT: FAIL (...)`.
5. `FAIL` — читай причину и хвост лога (`exports/verify/<id>.log`), правь, запускай снова.
   Не больше 5 попыток; потом шаг 6 с тем, что пробовал.
6. Допиши в конец тикета раздел `## Отчёт исполнителя`: что изменил (файл, константа,
   старое → новое значение), вывод последнего `verify.py` (строки тел и `VERDICT`), вопросы.

## Нельзя

- Трогать файлы вне `allowed`. Судья это видит и валит тикет.
- Править `archive/`, `mitrailleuse/` — никогда.
- Включать `CHECKS = True` в пистолете, если тикет не просит: полный свип ~40 с и не твоя задача.
- Писать «готово» без `VERDICT: PASS` в выводе. Нет FreeCAD — так и пиши, не выдумывай числа.
- Делать `git commit`, `git push`, `git checkout`, `git stash`, удалять файлы.
- Открывать FreeCAD GUI, MCP, слайсер. Только `tools/verify.py`.

## Мелочи, на которых падают

- Ошибка `UnicodeEncodeError` / «Ø» — судья сам ставит UTF-8; если запускаешь `freecadcmd`
  руками, сначала `export LANG=C.UTF-8 LC_ALL=C.UTF-8`.
- Файлы исполняют друг друга через `exec(open(...).read())`: правка в одном меняет сборку другого.
  Поэтому меряет судья, а не ты на глаз.
- Размеры в мм, объём в мм³. Ось x вперёд, z вверх.
- Докстринги и комментарии — по-английски, в стиле файла; тебе пишут по-русски.
